# ACS712 驱动验证

## 1. 验证目标

- 证明 ADC1 通道 0（PA0）能可靠采集模拟电压
- 测量 ACS712 模块的零点电压和满量程范围
- 用已知负载完成至少两点标定（零电流和已知电流）
- 验证 ADC 触发源、DMA 半/全缓冲中断和溢出处理
- 保存原始 ADC 码值、换算参数和参考仪表读数

## 2. 硬件连接

| ACS712 引脚 | 开发板引脚 | 备注 |
| --- | --- | --- |
| VCC | 5V | ACS712 工作电压 5V（板载稳压） |
| GND | GND | - |
| VOUT | PA0（经分压） | 输出 0-5V，需分压到 0-3.3V |
| IP+ / IP- | 被测负载回路 | **仅连接安全低压负载（<24V DC）** |

**检查项**：
- 确认 VOUT 经过分压电路（如 10 kΩ + 20 kΩ 分压）后输入 PA0，确保 PA0 电压 ≤ 3.3V
- 用万用表测量零电流时 VOUT 电压（理论值 2.5V）
- 确认被测负载为安全低压（LED 灯串、小风扇、电阻负载），**不接市电和高压设备**

**分压电路设计**（示例）：
```
ACS712 VOUT (0-5V) --> R1 (10 kΩ) --> PA0 --> R2 (20 kΩ) --> GND
PA0 电压 = VOUT × R2 / (R1 + R2) = VOUT × 20 / 30 = 0.667 × VOUT
最大输入：5V × 0.667 = 3.33V（接近但不超 3.3V）
```

## 3. CubeMX 配置

### 3.1 ADC1 配置

- **Mode**: Independent mode（单 ADC 模式）
- **Channel**: IN0（PA0）
- **Rank**: 1
- **Sampling Time**: 239.5 Cycles（增加采样时间以提高精度）
- **Continuous Conversion**: Enabled（连续转换模式）
- **Scan Conversion**: Disabled（单通道模式，暂不启用多通道）
- **Data Alignment**: Right（右对齐，12 位）
- **External Trigger**: Software trigger（软件触发）

### 3.2 DMA 配置

- **DMA Request**: ADC1
- **Direction**: Peripheral to Memory
- **Mode**: Circular（循环模式）
- **Peripheral Increment**: Disabled
- **Memory Increment**: Enabled
- **Peripheral Data Width**: Half Word (16 bits)
- **Memory Data Width**: Half Word (16 bits)
- **Priority**: High

### 3.3 中断配置

- **DMA1 Channel1**: 使能 Half Transfer Complete 和 Transfer Complete 中断
- **NVIC Priority**: 建议优先级 5（低于关键任务，高于空闲任务）

## 4. 驱动验证步骤

### 4.1 基础 ADC 采集（阻塞模式）

```c
// 1. 启动单次转换
HAL_ADC_Start(&hadc1);

// 2. 等待转换完成
if (HAL_ADC_PollForConversion(&hadc1, HAL_MAX_DELAY) == HAL_OK) {
    uint32_t adc_value = HAL_ADC_GetValue(&hadc1); // 12 位，0-4095
    printf("ADC Raw: %lu\r\n", adc_value);
}

// 3. 停止转换
HAL_ADC_Stop(&hadc1);
```

### 4.2 DMA 连续采集

```c
// 定义 DMA 缓冲区（双缓冲，每个缓冲区 64 个样本）
#define ADC_BUFFER_SIZE 128
uint16_t adc_buffer[ADC_BUFFER_SIZE];

// 启动 DMA 连续转换
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_buffer, ADC_BUFFER_SIZE);

// 半传输中断回调（前 64 个样本已填充）
void HAL_ADC_ConvHalfCpltCallback(ADC_HandleTypeDef* hadc) {
    if (hadc->Instance == ADC1) {
        // 处理 adc_buffer[0..63]
        Process_ADC_Data(&adc_buffer[0], ADC_BUFFER_SIZE / 2);
    }
}

// 全传输中断回调（后 64 个样本已填充）
void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef* hadc) {
    if (hadc->Instance == ADC1) {
        // 处理 adc_buffer[64..127]
        Process_ADC_Data(&adc_buffer[ADC_BUFFER_SIZE / 2], ADC_BUFFER_SIZE / 2);
    }
}
```

### 4.3 ADC 码值到电压的转换

```c
// STM32F103 ADC 参考电压 VREF+ = 3.3V，12 位分辨率
float adc_to_voltage(uint16_t adc_value) {
    return (adc_value / 4095.0f) * 3.3f; // PA0 电压（已分压）
}

// PA0 电压到 ACS712 VOUT 电压
float pa0_to_vout(float pa0_voltage) {
    // 根据分压比反推 VOUT
    // 若 PA0 = VOUT × 0.667，则 VOUT = PA0 / 0.667
    return pa0_voltage / 0.667f;
}

// ACS712 VOUT 到电流（20A 型，灵敏度 100 mV/A）
float vout_to_current(float vout) {
    // 零点 2.5V，灵敏度 0.1V/A
    // I = (VOUT - 2.5) / 0.1
    return (vout - 2.5f) / 0.1f;
}
```

### 4.4 完整换算流程

```c
uint16_t adc_raw = adc_buffer[0];
float pa0_voltage = adc_to_voltage(adc_raw);
float vout = pa0_to_vout(pa0_voltage);
float current_a = vout_to_current(vout);

printf("ADC=%u, PA0=%.3fV, VOUT=%.3fV, I=%.3fA\r\n", 
       adc_raw, pa0_voltage, vout, current_a);
```

## 5. 零点标定

### 5.1 测量零点电压

- **操作**：ACS712 的 IP+/IP- 不接任何负载（开路），或短接（零电流）
- **期望**：VOUT = 2.5V（理论值）
- **记录**：ADC 原始码值、PA0 电压、反推的 VOUT

```c
// 采集 100 次取平均
uint32_t sum = 0;
for (uint16_t i = 0; i < 100; i++) {
    HAL_ADC_Start(&hadc1);
    HAL_ADC_PollForConversion(&hadc1, HAL_MAX_DELAY);
    sum += HAL_ADC_GetValue(&hadc1);
    HAL_Delay(10);
}
uint16_t adc_zero = sum / 100;
float vout_zero = pa0_to_vout(adc_to_voltage(adc_zero));

printf("Zero point: ADC=%u, VOUT=%.3fV\r\n", adc_zero, vout_zero);
// 若偏差 > 0.1V，记录实际零点并用于后续换算
```

### 5.2 零点偏移修正

```c
// 若实际零点不是 2.5V，保存偏移量
float vout_zero_offset = vout_zero - 2.5f;

// 修正后的电流换算
float vout_to_current_corrected(float vout) {
    return (vout - vout_zero) / 0.1f;
}
```

## 6. 已知负载标定

### 6.1 标定点 1：小负载（约 0.5A）

- **操作**：接入 LED 灯串或小风扇（5V/0.5A），用万用表串联测量实际电流
- **记录**：
  - ADC 原始码值（平均 100 次）
  - 换算后的电流值
  - 万用表实际读数
  - 误差 = (换算值 - 实际值) / 实际值 × 100%

### 6.2 标定点 2：中等负载（约 2A）

- **操作**：接入已知阻性负载（如 12V/2A 风扇或电阻），用万用表串联测量实际电流
- **记录**：同上

### 6.3 线性度验证

- 绘制"ADC 码值 vs 实际电流"曲线
- 计算线性回归系数，验证 R² > 0.99

## 7. 测试场景

### 7.1 静态零电流

- **操作**：IP+/IP- 开路或短接
- **期望**：电流读数 < 0.1A（噪声范围内）
- **记录**：连续 100 次采样的标准差

### 7.2 恒定负载

- **操作**：接入稳定负载（如电阻或稳压风扇）
- **期望**：电流波动 < 5%
- **记录**：平均电流、峰峰值、万用表对照

### 7.3 阶跃负载

- **操作**：手动开关负载（如开关灯）
- **期望**：捕获到电流阶跃信号
- **记录**：阶跃前后的电流值和响应时间

### 7.4 连续采样（DMA 模式）

- **操作**：连续采集 1 秒（假设 ADC 时钟配置为 1 kHz，共 1000 个样本）
- **期望**：无 DMA 溢出、无数据丢失
- **记录**：DMA 半/全中断触发次数、缓冲区覆盖标志

## 8. 异常路径验证

### 8.1 ADC 饱和

- 人为输入 > 3.3V 电压到 PA0（通过可调电源和保护电阻）
- 验证 ADC 读数是否饱和在 4095
- 记录饱和标志并报告错误

### 8.2 DMA 溢出

```c
// 在 DMA 中断中设置标志位
volatile uint8_t dma_overrun_flag = 0;

void HAL_ADC_ErrorCallback(ADC_HandleTypeDef* hadc) {
    if (hadc->Instance == ADC1) {
        if (__HAL_ADC_GET_FLAG(hadc, ADC_FLAG_OVR)) {
            dma_overrun_flag = 1;
            printf("ADC DMA overrun detected\r\n");
            __HAL_ADC_CLEAR_FLAG(hadc, ADC_FLAG_OVR);
        }
    }
}
```

### 8.3 负载断开检测

- 若电流突然降为 0 且持续 > 3 秒，标记为负载断开
- 区分正常零电流和异常断开

## 9. 采样率和触发源配置

### 9.1 软件触发 + 连续转换

```c
// CubeMX 配置：
// - External Trigger: Software trigger
// - Continuous Conversion: Enabled
// 启动后 ADC 自动连续转换，无需手动触发
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_buffer, ADC_BUFFER_SIZE);
```

### 9.2 定时器触发（可选，用于精确采样率）

```c
// 配置 TIM2 触发 ADC1，采样率 1 kHz
// CubeMX 配置：
// - TIM2 Trigger Output: Update Event
// - ADC1 External Trigger: Timer 2 TRGO
// - Continuous Conversion: Disabled（由定时器控制）
HAL_TIM_Base_Start(&htim2);
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_buffer, ADC_BUFFER_SIZE);
```

### 9.3 采样时间计算

```c
// STM32F103 ADC 时钟 = APB2 / 6（假设 APB2 = 72 MHz）
// ADC 时钟 = 72 / 6 = 12 MHz
// 单次转换时间 = 采样时间 + 12.5 个时钟周期
// 采样时间 = 239.5 cycles
// 单次转换时间 = (239.5 + 12.5) / 12 MHz ≈ 21 μs
// 最大采样率 ≈ 1 / 21 μs ≈ 47 kHz（理论值，实际需考虑 DMA 和处理延迟）
```

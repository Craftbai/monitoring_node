# 物料与工具

本文件列出选型条件和验证工具，不替代实际[硬件基线](../hardware/硬件基线.md)。具体型号、版本、接线和测量设置在硬件基线实例中冻结；[硬件基线模板](../hardware/硬件基线模板.md)用于后续重建或复核字段，以下未签出的内容仍只能作为候选。

## 1. 硬件候选

| 类别 | 选型要求 | 用途与验收关注点 |
| --- | --- | --- |
| MCU 开发板 | 正点原子精英 STM32F103 开发板 V2，STM32F103ZET6/LQFP144；板载 LSE、CH340、LED、24C02 等资源 | 验证 DMA、Stop 唤醒、CMSIS-DSP 和调试链；64 KB SRAM 仍需显式预算缓冲和任务栈 |
| 调试器 | ST-Link 或等效调试器，能下载、单步和读取复位原因 | 保存下载日志、固件版本和复位信息 |
| 振动传感器 | SPI；有明确量程、ODR、带宽、FIFO/中断和供电电平 | 采集振动窗口并计算频带能量；不能只凭“加速度计”类别假定接口时序 |
| 温度传感器 | I2C；地址、转换时间、精度和测温位置明确 | 周期温度快照和阈值判断 |
| 电流前端 | 隔离或低压安全；输出不超过 ADC 输入；零点、比例、带宽和保护已知 | 连接低压直流风扇，完成 ADC 标定和趋势/电流特征 |
| 演示对象 | 可控的低压直流风扇或等效安全负载 | 产生可重复的正常、扰动和温升场景 |
| 测量仪器 | 万用表、示波器、逻辑分析仪、功耗分析仪 | 观察接口时序、DMA 触发、模拟波形和实际电流 |

### 选型门禁

- STM32F103ZET6 有 64 KB SRAM、无硬件 FPU；仍需先做双缓冲、FFT 工作区、任务栈和日志缓冲的静态预算，是否采用定点由目标板耗时和资源证据决定。
- 1024 点窗口只是当前样例，必须在真实采样块、FreeRTOS 栈水位和链接映射确认后冻结，不能因为配置样例可解析就视为资源已满足。
- 传感器输出数据率、SPI 吞吐和 FIFO 深度满足窗口长度；采样率必须覆盖目标频带并留出抗混叠余量。
- 所有电平与供电兼容；电流前端有明确的隔离或低压安全理由。
- 传感器可以在 Stop 前关闭或进入低功耗，唤醒后稳定时间不会超过周期预算。
- 板载 LED、调试器和 USB 转换器的漏电路径可以识别或在功耗测试时隔离。

## 2. 软件环境

### 目标板工具

- STM32CubeMX、STM32CubeIDE、对应 STM32Cube MCU Package。
- FreeRTOS、CMSIS 和 CMSIS-DSP，版本在硬件基线中固定。
- ST-Link 驱动/工具、串口终端和逻辑分析仪软件。

### PC 侧工具

- Python 3、NumPy、SciPy、Pandas、Matplotlib，用于 CSV 回放、浮点参考和曲线。
- Pytest，用于固定特征公式、阈值状态机和边界输入。
- PowerShell，用于配置解析、链接检查和可复现命令记录。

PC 依赖只服务离线参考与测试，不会自动成为 MCU 固件依赖。安装命令见根 README，安装前应记录 Python 和包版本。

## 3. 先确认的参数

在确定 FFT 点数、告警阈值和任务预算前，必须有以下事实：

1. 振动传感器实际 ODR、量程、灵敏度、带宽、FIFO 行为和安装方向。
2. 温度转换时间、精度、地址和安装位置。
3. 电流前端零点、比例、最大输出、电气隔离和标定仪表。
4. ADC 参考电压、采样时间、触发源和 DMA 半/全缓冲长度。
5. RTC 时钟源、Stop 模式、唤醒延迟和传感器重新稳定时间。
6. UART/无线链路的接口电平、最大消息长度、发送时延和失败策略。

## 4. 测量与记录要求

每次测量至少记录日期、板卡版本、供电电压、传感器配置、工具/仪器型号、采样设置和原始文件位置。功耗结果必须区分采集、处理、上报、Stop 和唤醒过渡，不能只记录一个平均值。

建议证据落点：

- `evidence/board/`：芯片 ID、工具版本、下载和复位日志。
- `evidence/sensors/`：原始读数、总线波形、标定记录和断线测试。
- `evidence/algorithm/`：CSV 样本、PC 结果、MCU 对照和误差统计。
- `evidence/power/`：电流波形、状态时长、供电条件和计算表。

这些目录在产生真实证据后再创建，不提前用空目录代表验证完成。

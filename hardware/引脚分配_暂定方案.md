# STM32F103ZET6 引脚分配（暂定方案）

## 适用范围

本表按 **正点原子精英 STM32F103 开发板 V2、STM32F103ZET6、LQFP144** 规划。板载连接依据为资料盘中的 `精英板V2 IO引脚分配表.xlsx` 和 `Elite_DNF103 V2.6.pdf`；芯片外设复用仍需在 STM32CubeMX 中以 `STM32F103ZET6` 目标重新校验。

资料表证明板载资源的设计连接，但不能证明用户手中实物的板卡修订、跳线帽位置和电气状态。接线前仍需核对 PCB 丝印、P3/P6/P7 等跳线、传感器模块电平和供电路径。本表在实物复核前保持“暂定”，不作为已经验证的接线施工图。

## 1. 推荐功能分配

| 功能 | STM32 引脚/外设 | 外接信号 | 说明 |
| --- | --- | --- | --- |
| JTAG 4 线调试 | `PA13 / JTMS`、`PA14 / JTCK`、`PA15 / JTDI`、`PB3 / JTDO`、`NRST`、`3V3`、`GND` | 支持完整 JTAG 的 ST-Link | 当前默认使用 JTAG (4 pins)，PB4/NJTRST 释放；PA13/PA14 仍兼具 SWDIO/SWCLK 功能 |
| 串口日志/上报 | `PA9 / USART1_TX`、`PA10 / USART1_RX` | 板载 CH340，P3 跳线选择 | 默认可通过 P3 连接 CH340；首版只用 UART，禁止把 5 V TTL 直接接入 RX |
| 振动 I2C 时钟 | `PB8 / I2C1_SCL` | `MPU6050_SCL` | **变更**：改用 MPU6050（I2C）替代 ADXL345（SPI） |
| 振动 I2C 数据 | `PB9 / I2C1_SDA` | `MPU6050_SDA` | 与 PB6/PB7 的 I2C1 不同，PB8/PB9 是 I2C1 的重映射引脚 |
| 振动数据就绪 | `PE2 / GPIO EXTI2` | `MPU6050_INT` | PE2 在 IO 表中完全独立，FIFO 满或数据就绪中断 |
| 温度 1-Wire | `PG9 / GPIO` | `DS18B20_DQ` | **变更**：改用 DS18B20（1-Wire）替代 TMP102（I2C）；PG9 需外接 4.7 kΩ 上拉 |
| 电流 ADC | `PA0 / ADC1_IN0` | `ACS712_OUT` | **变更**：改用 PA0（ADC1_IN0），避开 PC0 的 CAMERA 冲突；ADC1 + DMA，前端需先确认零点、比例和保护 |
| 传感器电源使能 | `PE6 / GPIO` | 外部负载开关 EN | PE6 在 IO 表中完全独立；不用电源开关时固定为安全电平 |
| 状态指示 | `PB5 / GPIO` | 板载 LED0/DS0（红色） | 板载专用 LED；暂按低有效设计，首次上电仍需验证极性 |
| 备用状态指示 | `PE5 / GPIO` | 板载 LED1/DS1（绿色） | 默认不占用；需要双色状态时再启用 |
| 测试时序标记 | `PD11 / GPIO` | 示波器/逻辑分析仪 | IO 表中完全独立，用于标记采集、处理和 Stop 区间 |
| RTC 低速晶振 | `PC14/OSC32_IN`、`PC15/OSC32_OUT` | 板载 32.768 kHz 晶振 | IO 表确认连接 RTC 晶振；启用 LSE 后不得再作普通 GPIO |

## 2. 资源和冲突约束

- `PA13/PA14/PA15/PB3/NRST` 按 JTAG (4 pins) 保留给调试器。PA15 同时连接 ATK-MODULE LED，PB3 同时连接 CAMERA/OLED WEN；使用 JTAG 时不要接入占用这两个信号的扩展模块。
- 若实际 ST-Link 只有 SWDIO/SWCLK 而没有 TDI/TDO，应把 CubeMX Debug 改回 `Serial Wire`，不能把两线接法当作完整 JTAG 接线。
- **振动传感器变更**：改用 MPU6050（I2C），使用 `PB8/PB9`（I2C1 重映射引脚）。释放原 SPI1 的 `PA5/PA6/PA7/PA4`，可用于其他功能。
- **温度传感器变更**：改用 DS18B20（1-Wire），使用 `PG9`。需外接 4.7 kΩ 上拉到 3.3V。释放原 I2C1 的 `PB6/PB7`，板载 AT24C02 仍可使用。
- **电流 ADC 变更**：从 `PC0` 改为 `PA0`（ADC1_IN0）。`PA0` 同时连接 KEY_UP/WK_UP，使用时需确认按键不影响 ADC 读数，或通过跳线断开按键。
- `PA0` 的 ADC 只能接经过保护和标定的低压模拟前端（0-3.3V），不能直接接风扇电源或市电。ACS712 模块输出必须确认为 0-3.3V 范围。
- `PB5` 已连接板载 LED0，仅作低速推挽输出；初始输出 High 以避免常见低有效 LED 上电点亮，实际极性由 M1 验证。
- `PD11` 作为测试 GPIO，替代旧方案的 PB12。PB12 已连接板载 W25Q128 的片选 `F_CS`，不得作为追踪脚。
- `PC14/PC15` 若启用 LSE，则不能再作为普通 GPIO 使用；Stop 唤醒需验证时钟恢复。
- `PB12/PB13/PB14/PB15` 连接板载 W25Q128/SPI2，预留给 M5-M7 阶段的 NRF24L01 无线模块；`PB0/PB1` 连接 TFTLCD 背光/触摸时钟，当前方案避免复用这些引脚。
- 当前方案只规划一个 ADC 电流通道。若之后要采三轴模拟振动，必须重新评估 ADC 通道、DMA 缓冲和 SRAM 预算。

## 3. 传感器购买建议

### 首版建议购买

| 类别 | 建议器件/模块 | 购买时必须确认 |
| --- | --- | --- |
| 振动 | `MPU6050` 3.3 V I2C 模块，带 `INT` 引脚 | 支持 I2C、I/O 电平为 3.3 V、地址可选（0x68/0x69）、FIFO 1024 字节、模块已配置上拉电阻 |
| 温度 | `DS18B20` 3.3 V 1-Wire 模块或裸片 | 1-Wire 接口、精度 ±0.5°C、转换时间 < 750 ms、模块需外接 4.7 kΩ 上拉或板上已有 |
| 电流 | `ACS712-20A` 模块（霍尔电流传感器） | 输出范围 0-5V（需分压到 0-3.3V）或直接 0-3.3V 模块、电气隔离 2.1 kV、灵敏度 100 mV/A |
| 电源与接线 | 3.3 V 稳压供电、杜邦线、面包板 | 所有模块共地，不能将 5 V 信号直接送入 ZET6 GPIO/ADC；MPU6050 和 DS18B20 模块需确认上拉配置 |

### 资料盘中的备选

- 资料盘包含 **MPU6050 完整资料**（`7，硬件资料/5，MPU6050资料/`），包含数据手册、驱动代码和示例工程。
- 资料盘包含 **DS18B20 数据手册**（`7，硬件资料/2，芯片资料/DS18B20.pdf`），单总线驱动可参考正点原子例程。
- **NRF24L01 模块**：资料盘包含完整资料（`7，硬件资料/8，NRF24L01模块资料/`），预留给 M5-M7 阶段的无线上报，将使用板载 SPI2（PB12/PB13/PB14/PB15）。
- 资料盘的 ADC、DMA、I2C、1-Wire、RTC、低功耗和 DSP 例程与精英 ZET6 板硬件更接近，但仍需核对例程版本、实际跳线和本项目已占用引脚，不能整包复制 BSP。

## 4. 复核顺序

1. 确认实物丝印为 STM32F103ZET6、封装为 LQFP144，板卡修订与精英板 V2 资料相符。
2. 核对 P3 跳线、供电选择和启动跳线，用 ST-Link 读取芯片 ID，建立 M1 最小工程。
3. 确认 P3 将 `PA9/PA10` 接到板载 CH340，并使用串口终端验证 3.3 V UART。
4. 验证 `PB5` LED0 极性、`PD11` 测试点、LSE 起振以及 `PB6/PB7` 的板载 4.7 kΩ 上拉。
5. 在 CubeMX 中按本表创建 GPIO/外设配置，再进行无传感器的 UART、RTC 和 Stop 冒烟。

本表完成实物复核并填写到 `hardware/硬件基线.md` 后，才升级为正式接线方案。

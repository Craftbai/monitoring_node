# 低功耗多参数状态监测节点

## 目标

在 STM32 + FreeRTOS 平台采集振动、温度和低压电流信号，完成滤波、特征提取、阈值告警和周期性低功耗上报。

## 最小闭环

1. SPI 振动传感器、I2C 温度传感器和 ADC 电流通道完成基础读取。
2. ADC 使用 DMA 双缓冲连续采集一个固定窗口。
3. 使用 CMSIS-DSP 计算 RMS、峰峰值、峰值因子和 FFT 频带能量。
4. 连续 N 个窗口超过阈值后触发告警，通过串口输出或发送到上位机。
5. 使用 RTC 周期唤醒，完成一次采样窗口和上报后进入 Stop；首版为周期性状态评估，不宣称连续振动监测。

## 目录说明

- `docs/`：功能边界、任务数据流、物料和验证要求。
- `config/`：采样、FFT 和阈值样例。
- `firmware/`：后续放置 STM32CubeIDE/FreeRTOS 工程。
- `tests/`：后续放置离线样本、算法对照和硬件测试记录。
- `hardware/`：接线、传感器和功耗测量记录。
- `tools/`：PC 侧数据分析依赖。

当前目录只包含启动资料和样例配置，尚未包含固件源码。

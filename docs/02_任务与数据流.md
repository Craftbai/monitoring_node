# 任务与数据流

## 建议任务划分

| 任务/上下文 | 职责 | 同步方式 |
| --- | --- | --- |
| DMA 回调 | 标记半缓冲或全缓冲就绪，不做耗时计算 | 任务通知或队列 |
| 采集任务 | 读取 SPI/I2C 传感器，管理采样窗口 | 队列/缓冲池 |
| 处理任务 | 滤波、窗函数、FFT、特征和告警判定 | 接收缓冲索引 |
| 上报任务 | 串口或无线发送结果，保存失败状态 | 队列 |
| 健康监测任务 | 检查任务心跳和总线错误计数 | 周期定时 |

看门狗只在关键任务均正常报告心跳后喂狗，不能由单个任务无条件喂狗。

## 数据流

`ADC + DMA 双缓冲 / SPI 振动数据 -> 缓冲索引 -> 处理任务 -> 特征结果 -> 告警状态 -> 上报任务`

首版 FFT 采用 2 的幂次采样点，例如 1024 点。若使用 Q15 定点格式，必须在离线脚本中与浮点参考结果对照并检查缩放和饱和。

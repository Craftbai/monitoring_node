# M2 阶段总览

本目录包含 M2 阶段"单设备驱动"的详细验证文档，按传感器类型分为三个独立验证任务。

## 阶段目标

分别证明 SPI/I2C/ADC DMA 可用，建立每个传感器的驱动代码和原始数据采集能力，验证 ID 读取、数据读取、超时处理和错误恢复路径。

## 推进原则

1. **独立验证**：每个传感器用独立小程序验证，不在本阶段引入 FFT、告警和无线通信
2. **证据驱动**：保存原始数据（CSV 格式）、配置参数、波形截图和对照测量值
3. **异常覆盖**：必须验证超时、断开、错误 ID、总线忙和 DMA 溢出等异常路径
4. **顺序灵活**：三个传感器可并行验证，但每个传感器必须通过退出门禁才能标记完成

## 验证顺序建议

### 方案 A：由简到难
1. DS18B20（1-Wire 协议简单，单根信号线，便于调试）
2. MPU6050（I2C 标准接口，驱动成熟）
3. ACS712（涉及模拟前端、分压、标定和 DMA）

### 方案 B：按关键性排序
1. MPU6050（振动监测是核心功能）
2. ACS712（电流监测涉及安全）
3. DS18B20（温度监测相对独立）

**建议采用方案 A**，先建立调试信心，再处理复杂接口。

## 常见问题

### Q1: I2C 通信失败，总是返回 HAL_TIMEOUT
- 检查 SCL/SDA 上拉电阻是否连接（4.7 kΩ 到 3.3V）
- 用示波器或逻辑分析仪检查 SCL/SDA 波形
- 确认 I2C 地址正确（MPU6050 默认 0x68，注意左移 1 位）
- 降低 I2C 速度到 100 kHz
- 检查 CubeMX 配置中的引脚复用是否正确

### Q2: DS18B20 返回固定值 85°C
- 这是 DS18B20 的上电默认值，表示未完成转换
- 增加转换等待时间（12 位分辨率需 750 ms）
- 检查上拉电阻是否连接
- 验证 1-Wire 时序是否正确（用示波器测量）

### Q3: ADC 读数一直是 0 或 4095
- 检查 PA0 引脚是否正确连接
- 用万用表测量 PA0 实际电压
- 确认 ADC 参考电压 VREF+ 已连接 3.3V
- 检查 ADC 时钟配置是否正确
- 验证 ADC 校准是否完成（某些 STM32 需要手动校准）

### Q4: DMA 传输中断不触发
- 确认 DMA 中断在 NVIC 中已使能
- 检查 DMA 通道配置是否正确（ADC1 对应 DMA1 Channel1）
- 验证 ADC 是否成功启动（HAL_ADC_Start_DMA 返回 HAL_OK）
- 检查缓冲区大小是否为偶数（便于半/全中断）

### Q5: 如何选择采样率？
- MPU6050：振动监测需覆盖目标频段，建议 1 kHz 起步（Nyquist 频率 500 Hz）
- DS18B20：温度变化慢，1 Hz 足够（受限于转换时间 750 ms）
- ACS712：电流监测根据负载特性，建议 1 kHz（可捕获开关瞬态）

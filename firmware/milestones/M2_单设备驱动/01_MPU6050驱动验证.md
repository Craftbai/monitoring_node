# MPU6050 驱动验证

## 1. 验证目标

- 证明 I2C1（PB8/SCL、PB9/SDA）能可靠读写 MPU6050 寄存器
- 读取 WHO_AM_I 验证器件 ID（期望 0x68）
- 配置加速度量程、输出数据率、低通滤波器和 FIFO
- 采集三种工况下的原始三轴加速度数据
- 验证 I2C 超时、错误 ID、FIFO 溢出和器件软复位恢复路径

## 2. 硬件连接

| MPU6050 引脚 | 开发板引脚 | 备注 |
| --- | --- | --- |
| VCC | 3.3V | 不接 5V |
| GND | GND | - |
| SCL | PB8 | I2C1_SCL 重映射 |
| SDA | PB9 | I2C1_SDA 重映射 |
| INT | PE2 | FIFO 满或数据就绪中断（本阶段暂不启用） |
| AD0 | GND | I2C 地址 0x68（若接 VCC 则为 0x69） |

**检查项**：
- 确认 MPU6050 模块已连接 SCL/SDA 上拉电阻（典型 4.7 kΩ）
- 用万用表确认模块供电为 3.3V
- 确认 AD0 接地，器件地址为 0x68

## 3. CubeMX 配置

### 3.1 I2C1 配置

- **Mode**: I2C
- **Pins**: PB8 (I2C1_SCL), PB9 (I2C1_SDA)
- **I2C Speed**: Standard Mode (100 kHz) 或 Fast Mode (400 kHz)，优先 100 kHz 验证稳定性
- **DMA**: 本阶段不启用，先用阻塞/轮询 API

### 3.2 GPIO 配置

- PE2 配置为 GPIO_EXTI2（备用，本阶段暂不启用中断）

### 3.3 时钟配置

- 确认 APB1 时钟已使能（I2C1 挂载在 APB1）
- 记录 APB1 频率，用于计算 I2C 时序参数

## 4. 驱动验证步骤

### 4.1 基础通信验证

```c
// 1. 读取 WHO_AM_I 寄存器（0x75）
uint8_t who_am_i = 0;
HAL_I2C_Mem_Read(&hi2c1, MPU6050_ADDR << 1, 0x75, 1, &who_am_i, 1, HAL_MAX_DELAY);
// 期望值：0x68

// 2. 验证器件存在
if (who_am_i == 0x68) {
    printf("MPU6050 ID: 0x%02X - OK\r\n", who_am_i);
} else {
    printf("MPU6050 ID: 0x%02X - ERROR (expected 0x68)\r\n", who_am_i);
}
```

### 4.2 配置寄存器

```c
// 1. 解除休眠（PWR_MGMT_1 = 0x00）
uint8_t pwr_mgmt = 0x00;
HAL_I2C_Mem_Write(&hi2c1, MPU6050_ADDR << 1, 0x6B, 1, &pwr_mgmt, 1, HAL_MAX_DELAY);
HAL_Delay(100); // 等待器件稳定

// 2. 配置加速度量程（ACCEL_CONFIG = 0x00, ±2g）
uint8_t accel_config = 0x00; // FS_SEL = 0
HAL_I2C_Mem_Write(&hi2c1, MPU6050_ADDR << 1, 0x1C, 1, &accel_config, 1, HAL_MAX_DELAY);

// 3. 配置采样率分频（SMPLRT_DIV = 0x07, 1 kHz / 8 = 125 Hz）
uint8_t smplrt_div = 0x07;
HAL_I2C_Mem_Write(&hi2c1, MPU6050_ADDR << 1, 0x19, 1, &smplrt_div, 1, HAL_MAX_DELAY);

// 4. 配置低通滤波器（CONFIG = 0x06, BW = 5 Hz）
uint8_t config = 0x06;
HAL_I2C_Mem_Write(&hi2c1, MPU6050_ADDR << 1, 0x1A, 1, &config, 1, HAL_MAX_DELAY);
```

### 4.3 读取原始数据

```c
// 连续读取 ACCEL_XOUT_H ~ ACCEL_ZOUT_L（14 字节，包含温度）
uint8_t raw_data[14];
HAL_I2C_Mem_Read(&hi2c1, MPU6050_ADDR << 1, 0x3B, 1, raw_data, 14, HAL_MAX_DELAY);

// 解析三轴加速度（16 位有符号数，±2g 量程，LSB = 16384）
int16_t accel_x = (raw_data[0] << 8) | raw_data[1];
int16_t accel_y = (raw_data[2] << 8) | raw_data[3];
int16_t accel_z = (raw_data[4] << 8) | raw_data[5];

// 转换为 g（地球重力加速度）
float ax_g = accel_x / 16384.0f;
float ay_g = accel_y / 16384.0f;
float az_g = accel_z / 16384.0f;

printf("Accel: X=%.3f g, Y=%.3f g, Z=%.3f g\r\n", ax_g, ay_g, az_g);
```

## 5. 测试场景

### 5.1 静止场景

- **操作**：开发板平放在水平桌面，保持静止 10 秒
- **期望**：X ≈ 0 g，Y ≈ 0 g，Z ≈ +1 g（重力方向）
- **记录**：原始 ADC 码值、换算后的 g 值、10 次采样的标准差

### 5.2 轻敲场景

- **操作**：用手指轻敲开发板或 MPU6050 模块 5 次
- **期望**：X/Y/Z 出现瞬时峰值，幅值 > 0.5 g
- **记录**：峰值时刻的三轴原始数据

### 5.3 风扇运行场景

- **操作**：将 MPU6050 固定在小风扇外壳上（安全、低压），启动风扇
- **期望**：出现周期性振动信号，频率可识别
- **记录**：连续 1 秒（125 个样本）的三轴原始数据，保存为 CSV

## 6. 异常路径验证

### 6.1 I2C 超时

```c
// 设置较短超时（如 10 ms）
HAL_StatusTypeDef status = HAL_I2C_Mem_Read(&hi2c1, MPU6050_ADDR << 1, 0x75, 1, &who_am_i, 1, 10);
if (status == HAL_TIMEOUT) {
    printf("I2C timeout detected\r\n");
    // 执行总线复位
    HAL_I2C_DeInit(&hi2c1);
    HAL_I2C_Init(&hi2c1);
}
```

### 6.2 错误 ID

- 人为读取错误地址（如 0x69），期望返回非 0x68 值
- 验证驱动能识别并报告错误

### 6.3 FIFO 溢出（可选，本阶段暂不启用 FIFO）

- 配置 FIFO 使能，但不及时读取
- 验证 FIFO_COUNT 超过 1024 时能检测到溢出

### 6.4 器件软复位

```c
// 写入 PWR_MGMT_1 寄存器的 DEVICE_RESET 位（bit 7）
uint8_t reset_cmd = 0x80;
HAL_I2C_Mem_Write(&hi2c1, MPU6050_ADDR << 1, 0x6B, 1, &reset_cmd, 1, HAL_MAX_DELAY);
HAL_Delay(100); // 等待复位完成
// 重新读取 WHO_AM_I，验证器件恢复
```

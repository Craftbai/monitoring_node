# 物料与工具

## 硬件起步清单

| 类别 | 建议材料 | 用途 |
| --- | --- | --- |
| MCU | STM32L4 开发板和 ST-Link | 低功耗、DMA、FreeRTOS 与 CMSIS-DSP |
| 振动 | SPI 接口低功耗加速度计 | 获取振动采样数据 |
| 温度 | I2C 温度传感器 | 获取温度趋势 |
| 电流 | 隔离或低压模拟电流传感器前端 | 接入 ADC 进行演示采集 |
| 演示对象 | 低压直流风扇 | 产生可控的振动和电流变化 |
| 调试 | 逻辑分析仪、示波器 | 检查 I2C/SPI/DMA 和模拟前端 |
| 功耗 | PPK2、Joulescope 或等价功耗分析仪 | 测量运行、Stop 与唤醒电流 |

## 软件工具

- STM32CubeMX、STM32CubeIDE、FreeRTOS、CMSIS-DSP、ST-Link 工具。
- Python 3、NumPy、SciPy、Pandas、Matplotlib，用于离线回放和算法对照。
- 串口终端、逻辑分析仪软件和示波器软件。

## 先决条件

先确认传感器采样率、接口时序、供电电压、实际可观测频段和安全隔离方式，再确定 FFT 点数与告警阈值。

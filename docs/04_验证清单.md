# 验证清单

## 驱动与任务

- [ ] I2C/SPI 设备正常读写，超时后能够完成总线恢复或错误上报。
- [ ] ADC DMA 半缓冲和全缓冲回调均可稳定处理，不覆盖未处理数据。
- [ ] 任意任务卡死或总线连续错误时，健康监测不会继续无条件喂狗。

## 算法与告警

- [ ] 使用已保存的样本验证 RMS、峰峰值、峰值因子和 FFT 频带能量。
- [ ] Q15 FFT 结果与 Python 浮点参考结果在可接受误差内一致。
- [ ] 正常、轻微异常和持续异常三类输入能验证连续确认逻辑。

## 低功耗与证据

- [ ] 测量采集、处理、上报和 Stop 四种状态的电流。
- [ ] RTC 周期唤醒后可恢复采集和上报，不丢失任务状态。
- [ ] 保存原始采样、特征结果、功耗曲线、串口日志和演示视频。

# DS18B20 驱动验证

## 1. 验证目标

- 证明 1-Wire 协议在 PG9 引脚上能可靠通信
- 读取 DS18B20 的 64 位 ROM 码（器件唯一 ID）
- 配置温度分辨率（9-12 位）和转换时间
- 采集至少两个温度点的原始数据，并与可信温度计对照
- 验证设备断开、总线忙和 1-Wire 恢复路径

## 2. 硬件连接

| DS18B20 引脚 | 开发板引脚 | 备注 |
| --- | --- | --- |
| VDD | 3.3V | 正常供电模式（非寄生供电） |
| GND | GND | - |
| DQ | PG9 | 数据线，需外接 4.7 kΩ 上拉到 3.3V |

**检查项**：
- 确认 DQ 引脚已连接 4.7 kΩ 上拉电阻到 3.3V
- 用万用表测量静态时 DQ 电压应为 3.3V
- 多个 DS18B20 可并联在同一条总线上，本阶段仅接一个器件

## 3. CubeMX 配置

### 3.1 GPIO 配置

- **PG9**: GPIO_Output（初始高电平）+ GPIO_Input（读取时切换）
- **模式**: 开漏输出（Open-Drain），外部上拉
- **速度**: High（50 MHz）
- **上拉/下拉**: 无（外部已有上拉电阻）

**注意**：1-Wire 协议需要软件位操作，CubeMX 不提供硬件 1-Wire 外设，需手动实现时序。

### 3.2 定时器配置（可选，用于精确延时）

- **TIM2**: 基础定时器，1 μs 时基
- **Prescaler**: (APB1_Clock / 1,000,000) - 1
- **Period**: 0xFFFF（16 位自由运行）
- 用于 1-Wire 时序的微秒级延时

## 4. 1-Wire 协议实现

### 4.1 关键时序参数（标准速度）

| 时序 | 最小值 (μs) | 典型值 (μs) | 最大值 (μs) |
| --- | --- | --- | --- |
| 复位脉冲宽度 | 480 | 480 | 960 |
| 存在脉冲等待 | 15 | 60 | 60 |
| 存在脉冲宽度 | 60 | 60 | 240 |
| 写 0 低电平 | 60 | 60 | 120 |
| 写 1 低电平 | 1 | 1 | 15 |
| 读时隙低电平 | 1 | 1 | 15 |
| 恢复时间 | 1 | 1 | - |

### 4.2 基础操作函数

```c
// 1. 初始化（复位并检测存在脉冲）
uint8_t DS18B20_Init(void) {
    uint8_t presence = 0;
    
    // 拉低至少 480 μs
    HAL_GPIO_WritePin(GPIOG, GPIO_PIN_9, GPIO_PIN_RESET);
    Delay_us(480);
    
    // 释放总线
    HAL_GPIO_WritePin(GPIOG, GPIO_PIN_9, GPIO_PIN_SET);
    Delay_us(70); // 等待存在脉冲
    
    // 读取总线状态（低电平表示器件存在）
    presence = HAL_GPIO_ReadPin(GPIOG, GPIO_PIN_9);
    Delay_us(410); // 完成复位时隙
    
    return !presence; // 1 = 存在，0 = 无响应
}

// 2. 写一位
void DS18B20_WriteBit(uint8_t bit) {
    HAL_GPIO_WritePin(GPIOG, GPIO_PIN_9, GPIO_PIN_RESET);
    Delay_us(bit ? 1 : 60); // 写 1 保持 1 μs，写 0 保持 60 μs
    HAL_GPIO_WritePin(GPIOG, GPIO_PIN_9, GPIO_PIN_SET);
    Delay_us(bit ? 60 : 1); // 剩余时间
}

// 3. 读一位
uint8_t DS18B20_ReadBit(void) {
    uint8_t bit = 0;
    
    HAL_GPIO_WritePin(GPIOG, GPIO_PIN_9, GPIO_PIN_RESET);
    Delay_us(1); // 启动读时隙
    HAL_GPIO_WritePin(GPIOG, GPIO_PIN_9, GPIO_PIN_SET);
    Delay_us(14); // 等待器件输出
    
    bit = HAL_GPIO_ReadPin(GPIOG, GPIO_PIN_9);
    Delay_us(45); // 完成读时隙
    
    return bit;
}

// 4. 写一字节
void DS18B20_WriteByte(uint8_t byte) {
    for (uint8_t i = 0; i < 8; i++) {
        DS18B20_WriteBit(byte & 0x01);
        byte >>= 1;
    }
}

// 5. 读一字节
uint8_t DS18B20_ReadByte(void) {
    uint8_t byte = 0;
    for (uint8_t i = 0; i < 8; i++) {
        byte >>= 1;
        if (DS18B20_ReadBit()) {
            byte |= 0x80;
        }
    }
    return byte;
}
```

## 5. 驱动验证步骤

### 5.1 检测器件存在

```c
if (DS18B20_Init()) {
    printf("DS18B20 detected\r\n");
} else {
    printf("DS18B20 not found\r\n");
}
```

### 5.2 读取 ROM 码（64 位唯一 ID）

```c
uint8_t rom[8];

DS18B20_Init();
DS18B20_WriteByte(0x33); // READ ROM 命令
for (uint8_t i = 0; i < 8; i++) {
    rom[i] = DS18B20_ReadByte();
}

printf("ROM: %02X-%02X%02X%02X%02X%02X%02X-%02X\r\n",
       rom[0], rom[6], rom[5], rom[4], rom[3], rom[2], rom[1], rom[7]);
// 格式：Family Code - Serial Number - CRC
// Family Code = 0x28（DS18B20）
```

### 5.3 读取温度

```c
int16_t DS18B20_ReadTemperature(void) {
    uint8_t temp_lsb, temp_msb;
    int16_t temp_raw;
    
    // 1. 启动转换
    DS18B20_Init();
    DS18B20_WriteByte(0xCC); // SKIP ROM（单器件模式）
    DS18B20_WriteByte(0x44); // CONVERT T
    HAL_Delay(750); // 等待转换完成（12 位分辨率需 750 ms）
    
    // 2. 读取暂存器
    DS18B20_Init();
    DS18B20_WriteByte(0xCC); // SKIP ROM
    DS18B20_WriteByte(0xBE); // READ SCRATCHPAD
    
    temp_lsb = DS18B20_ReadByte();
    temp_msb = DS18B20_ReadByte();
    
    // 3. 合成 16 位温度值
    temp_raw = (temp_msb << 8) | temp_lsb;
    
    return temp_raw; // LSB = 0.0625°C
}

// 转换为摄氏度
float temp_celsius = DS18B20_ReadTemperature() * 0.0625f;
printf("Temperature: %.2f °C\r\n", temp_celsius);
```

## 6. 测试场景

### 6.1 室温测量

- **操作**：开发板置于室内，静置 5 分钟后读取温度
- **期望**：温度在 20-30°C 之间
- **对照**：用数字温度计（精度 ±0.5°C）测量同一位置温度
- **记录**：DS18B20 读数、温度计读数、差值

### 6.2 低温测量（可选）

- **操作**：将 DS18B20 靠近冰袋或冰水（0°C）
- **期望**：温度接近 0°C
- **记录**：DS18B20 读数、实际环境温度

### 6.3 高温测量（可选，注意安全）

- **操作**：将 DS18B20 靠近温热物体（如暖水杯，<50°C）
- **期望**：温度升高
- **记录**：DS18B20 读数、实际环境温度

### 6.4 连续采样稳定性

- **操作**：连续采样 100 次，每次间隔 1 秒
- **期望**：温度波动 < 1°C（室温稳定环境）
- **记录**：平均值、标准差、最大波动

### 7.2 CRC 校验（可选）

```c
// DS18B20 返回的 9 字节暂存器最后一字节是 CRC8
uint8_t scratchpad[9];
for (uint8_t i = 0; i < 9; i++) {
    scratchpad[i] = DS18B20_ReadByte();
}

uint8_t crc = DS18B20_CRC8(scratchpad, 8);
if (crc != scratchpad[8]) {
    printf("CRC error: calculated 0x%02X, received 0x%02X\r\n", crc, scratchpad[8]);
    return SENSOR_ERROR_CRC;
}
```

## 8. 分辨率配置（可选）

DS18B20 支持 9/10/11/12 位分辨率，转换时间分别为 93.75 / 187.5 / 375 / 750 ms。

```c
// 写入配置寄存器（暂存器字节 2、3、4）
DS18B20_Init();
DS18B20_WriteByte(0xCC); // SKIP ROM
DS18B20_WriteByte(0x4E); // WRITE SCRATCHPAD

DS18B20_WriteByte(0x00); // TH（高温告警，本项目不用）
DS18B20_WriteByte(0x00); // TL（低温告警，本项目不用）
DS18B20_WriteByte(0x7F); // Config = 0x7F（12 位分辨率，bit 5-6 = 11）

// 保存到 EEPROM
DS18B20_Init();
DS18B20_WriteByte(0xCC);
DS18B20_WriteByte(0x48); // COPY SCRATCHPAD
HAL_Delay(10); // 等待写入完成
```

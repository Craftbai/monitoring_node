## 下一步行动建议

### 选项 1：从 DS18B20 开始（推荐）

**理由**：1-Wire 协议最简单，单根信号线，便于建立调试信心。

**步骤**：
1. 阅读 `02_DS18B20驱动验证.md`
2. 在 CubeIDE 中创建 `ds18b20.c` 和 `ds18b20.h` 驱动文件
3. 实现 1-Wire 协议基础函数（初始化、写位、读位、写字节、读字节）
4. 连接 DS18B20 硬件（PG9，4.7 kΩ 上拉）
5. 验证器件存在和 ROM 码读取
6. 采集室温数据并与温度计对照
7. 保存数据到 `data/ds18b20_room_temp.csv`

### 选项 2：从 MPU6050 开始

**理由**：振动监测是项目核心功能，优先验证。

**步骤**：
1. 阅读 `01_MPU6050驱动验证.md`
2. 在 CubeIDE 中创建 `mpu6050.c` 和 `mpu6050.h` 驱动文件
3. 使用 HAL I2C API 读取 WHO_AM_I 寄存器
4. 配置量程、采样率和滤波器
5. 连接 MPU6050 硬件（PB8/PB9，确认上拉电阻）
6. 采集静止、轻敲、风扇三种场景数据
7. 保存数据到 `data/mpu6050_*.csv`

### 选项 3：从 ACS712 开始

**理由**：需要最多的硬件准备（分压电路、标定负载），适合最后进行。

**步骤**：
1. 阅读 `03_ACS712驱动验证.md`
2. 设计并焊接分压电路（10 kΩ + 20 kΩ）
3. 在 CubeIDE 中创建 `acs712.c` 和 `acs712.h` 驱动文件
4. 使用 HAL ADC API 验证单次转换
5. 测量零点电压
6. 准备已知负载（LED 灯串、风扇）和万用表
7. 完成两点标定
8. 验证 DMA 连续采集
9. 保存数据到 `data/acs712_*.csv`

## 驱动代码建议结构

每个传感器驱动应包含：

```c
// xxx_sensor.h
typedef enum {
    SENSOR_OK = 0,
    SENSOR_ERROR_NOT_PRESENT,
    SENSOR_ERROR_TIMEOUT,
    SENSOR_ERROR_CRC,
    SENSOR_ERROR_INVALID_DATA
} sensor_status_t;

sensor_status_t Sensor_Init(void);
sensor_status_t Sensor_Read(float* output);
sensor_status_t Sensor_Reset(void);
```

## 调试技巧

### 1. UART 日志输出

确认 `main.c` 中已实现 `printf` 重定向到 USART1：

```c
#ifdef __GNUC__
int _write(int fd, char *ptr, int len) {
    HAL_UART_Transmit(&huart1, (uint8_t*)ptr, len, HAL_MAX_DELAY);
    return len;
}
#endif
```

### 2. 时间戳函数

实现微秒级延时和时间戳函数：

```c
// 基于 SysTick 的微秒延时
void Delay_us(uint32_t us) {
    uint32_t start = DWT->CYCCNT;
    uint32_t cycles = us * (SystemCoreClock / 1000000);
    while ((DWT->CYCCNT - start) < cycles);
}

// 毫秒时间戳
uint32_t Get_Timestamp_ms(void) {
    return HAL_GetTick();
}
```

### 3. 错误处理模板

```c
sensor_status_t status = Sensor_Read(&value);
if (status != SENSOR_OK) {
    printf("Sensor error: %d\r\n", status);
    // 尝试复位
    Sensor_Reset();
    return;
}
printf("Sensor value: %.3f\r\n", value);
```

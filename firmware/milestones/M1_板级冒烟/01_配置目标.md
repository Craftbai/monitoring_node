# M1 配置目标

本文档记录 M1 阶段（板级冒烟测试）的配置目标和退出门禁。

---

## 1. M1 阶段总览

### 1.1 阶段目标

验证 STM32F103ZET6 开发板的基础硬件功能，确保固件工程可以编译、下载并运行。

### 1.2 子阶段划分

| 子阶段 | 目标 | 验证方式 |
| --- | --- | --- |
| M1-A | CubeMX 工程生成和编译通过 | CubeIDE 编译无错误 |
| M1-B | 板级硬件验证 | 实测 UART/LED/RTC/Stop |

---

## 2. M1-A：工程生成和编译验证

### 2.1 配置内容

#### 2.1.1 系统核心配置

| 配置项 | 值 | 说明 |
| --- | --- | --- |
| MCU 型号 | STM32F103ZET6 | LQFP144，512KB Flash，64KB SRAM |
| Debug 接口 | JTAG (4 pins) | PA13/PA14/PA15/PB3 + NRST |
| HSE | 8 MHz Crystal | 外部高速晶体 |
| LSE | 32.768 kHz Crystal | 外部低速 RTC 晶体 |
| SYSCLK | 72 MHz | HSE → PLL ×9 |
| HCLK | 72 MHz | AHB 不分频 |
| PCLK1 | 36 MHz | APB1 /2 |
| PCLK2 | 72 MHz | APB2 不分频 |

#### 2.1.2 外设配置

| 外设 | 引脚 | 配置 | 用途 |
| --- | --- | --- | --- |
| USART1 | PA9/PA10 | 115200 8N1 | 日志输出 |
| GPIO | PB5 | Output Push-Pull | LED0 |
| GPIO | PD11 | Output Push-Pull, High Speed | TRACE_PIN（示波器测试） |
| I2C1 | PB8/PB9 | 100 kHz | 温度和振动传感器（重映射） |
| GPIO | PE2 | EXTI Rising Edge | MPU6050_INT |
| GPIO | PG9 | Output Open Drain, Pull-up | DS18B20_DQ（1-Wire） |
| ADC1 | PA0 | 12-bit, 28.5 cycles | 电流传感器 |
| RTC | LSE | Calendar + Alarm | 周期唤醒 |

**重要**：I2C1 必须使用重映射引脚 PB8/PB9，不能使用默认的 PB6/PB7（硬件冲突）。

### 2.2 退出门禁

- [x] CubeMX 工程创建成功（STM32F103ZET6，72 MHz，HAL 库）
- [x] 时钟树配置正确（HSE 8 MHz、PLL ×9、LSE 32.768 kHz）
- [x] 外设引脚分配符合硬件基线
- [x] I2C1 引脚正确（PB8/PB9，非默认 PB6/PB7）
- [x] ADC 采样时间优化（28.5 cycles）
- [x] 代码生成无警告或错误
- [x] CubeIDE 编译通过（0 errors, 0 warnings）
- [x] 生成 `.elf` 和 `.bin` 文件

## 4. M1 关键约束

### 4.1 硬件约束

- **调试接口冲突**：PA15（JTAG TDI）和 PB3（JTAG TDO）同时连接扩展模块，调试期间不要接入 ATK-MODULE 和摄像头模块
- **I2C 引脚重映射**：必须使用 PB8/PB9，不能使用默认的 PB6/PB7（与其他外设冲突）
- **ADC 采样冲突**：PA0 同时连接 KEY_UP 按键，ADC 采样时不要按 KEY_UP
- **LSE 起振风险**：32.768 kHz 晶振对 PCB 布局和负载电容敏感，若不起振则备选 LSI（40 kHz，精度较低）

### 4.2 软件约束

- **用户代码位置**：所有用户代码必须放在 `USER CODE BEGIN` 和 `USER CODE END` 之间，否则重新生成代码时会丢失
- **Stop 唤醒后时钟恢复**：Stop 模式会关闭 HSE 和 PLL，唤醒后必须调用 `SystemClock_Config()` 恢复 72 MHz
- **printf 重定向**：需要手动实现 `_write()` 函数，将 `printf` 输出重定向到 USART1
- **UART 发送完成**：进入 Stop 模式前必须确保 UART 数据发送完成（`HAL_Delay(100)`），否则日志会丢失

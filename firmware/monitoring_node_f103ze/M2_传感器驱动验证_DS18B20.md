# M2 阶段：DS18B20 温度传感器驱动验证

## 目标
验证 DS18B20 数字温度传感器驱动的正确性，为后续温度采集模块提供可靠的底层接口。

## 完成情况

### 1. 驱动实现 ✅
创建了完整的 DS18B20 驱动层：

**核心文件**：
- `App/Drivers/ds18b20.h` - API 接口定义
- `App/Drivers/ds18b20.c` - 1-Wire 协议实现
- `App/Drivers/test_ds18b20.h` - 测试接口
- `App/Drivers/test_ds18b20.c` - 完整测试套件

**驱动特性**：
- 1-Wire 软件位操作（复位、写位、读位）
- 器件初始化和存在脉冲检测
- ROM 码读取（64 位唯一 ID）
- 温度转换和读取（支持 -55°C ~ +125°C）
- CRC8 校验（Dallas/Maxim 算法）
- 分辨率配置（9/10/11/12 位可选）

### 2. 测试用例 ✅
实现了 4 个测试场景，覆盖正常和异常情况：

#### 测试 1：器件检测和 ROM 读取
- 验证 1-Wire 存在脉冲
- 读取 8 字节 ROM 码
- 检查 Family Code (0x28)
- CRC 校验

**预期输出**：
```
[PASS] DS18B20 存在脉冲检测成功
[PASS] ROM 读取成功
       Family Code: 0x28
       Serial Number: XXXXXXXXXXXX
       CRC: 0xXX
```

#### 测试 2：温度读取
- 连续采样 10 次，间隔 2 秒
- 原始值 + 浮点值显示
- 温度合理性检查（[-10, +50]°C）

**预期输出**：
```
[01] 温度: +23.50 °C (原始值: 0x0176)
[02] 温度: +23.62 °C (原始值: 0x0178)
...
```

**手动验证**：
- 室温读取：应在 20-30°C
- 手握传感器：温度上升至少 2°C
- 冰水测试：温度下降至 5°C 以下

#### 测试 3：分辨率配置
- 遍历 4 种分辨率（9/10/11/12 位）
- 设置后回读验证
- 恢复默认 12 位

**预期输出**：
```
设置分辨率: 9-bit
[PASS] 分辨率回读匹配: 0x1F
设置分辨率: 10-bit
[PASS] 分辨率回读匹配: 0x3F
...
```

#### 测试 4：异常场景
- 断线检测（拔掉 DQ 引脚）
- 自动恢复（重新连接后）

**预期输出**：
```
[PASS] 正确检测到传感器断线
[PASS] 传感器重新连接成功
```

### 3. 硬件连接 ⚠️
```
DS18B20           STM32F103ZET6
--------          --------------
DQ    ----------- PG9 + 4.7kΩ 上拉到 3.3V
VDD   ----------- 3.3V
GND   ----------- GND
```

**关键要求**：
- ✅ PG9 引脚选择（来自引脚分配方案）
- ⚠️ **4.7kΩ 上拉电阻必须接**（1-Wire 协议要求）
- ✅ 使用 3.3V 供电（不要用寄生供电模式）

### 2. 微秒延时校准 ⚠️
当前使用简单循环实现延时，**需要根据实际波形校准**：

**推荐方案：启用 DWT 计数器**（精确到 CPU 周期）
在 `main.c` 的 `SystemClock_Config()` 后添加：
```c
CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;
DWT->CYCCNT = 0;
DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;
```

然后在 `ds18b20.c` 中启用 DWT 方法（取消注释对应代码块）。

**备选方案：调整循环系数**
如果 DWT 不可用，用逻辑分析仪测量实际延时，调整 `DS18B20_DelayUs()` 中的循环次数。

### 4. 调试工具

- 检查 PG9 空闲电平（应为 3.3V，上拉电阻作用）
- 检查 VDD 和 GND 连接

**逻辑分析仪**：
- 捕获 1-Wire 波形
- 对照数据手册验证时序参数：

  - 存在脉冲：60-240 μs
  - 写 0：60-120 μs 低电平
  - 写 1：1-15 μs 低电平
  - 读位：1-15 μs 低电平，15 μs 内采样

**串口调试**：
- 115200 bps，8N1
- 查看测试输出和错误信息

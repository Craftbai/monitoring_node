# 低功耗多参数状态监测节点

## 项目定位

本项目计划在正点原子精英 STM32F103 开发板 V2（STM32F103ZET6、LQFP144）+ FreeRTOS 平台上，对低压直流风扇等安全演示对象进行振动、温度和电流的周期性状态评估。节点按 RTC 周期唤醒，采集固定长度窗口，完成时域/频域特征提取、连续超限判定和结果上报，随后进入 Stop 模式。

首版不是连续在线振动监测系统，不直接采样市电，不接入生产停机联锁。功能范围与限制以 [需求与边界](docs/01_需求与边界.md) 为准。

## 当前状态

仓库已完成 **M1 工程生成与主机侧构建基线**：目标为正点原子精英板 V2 / STM32F103ZET6，`.ioc`、`Core/`、`Drivers/`、启动文件、链接脚本和 `Debug/monitoring_node_f103ze.elf` 已生成；传感器型号、模拟前端、上报链路、实物 PCB 修订和目标板运行证据仍未冻结。

因此现在可以开始 STM32F1 工程冒烟、环境核对、传感器选型和 PC 算法参考；在传感器和引脚基线确认前，不应直接编写绑定具体器件的正式驱动。

## 如何开始

1. 阅读 [需求与边界](docs/01_需求与边界.md)，确认首版只做周期性状态评估。
2. 按 [硬件基线模板](hardware/硬件基线模板.md) 冻结开发板、三个传感通道、调试器、供电和上报方式。
3. 依照 [开发路线图](docs/05_开发路线图.md) 完成 M0；退出门禁是基线中没有“待确认”的关键项。
4. 使用 STM32CubeMX/STM32CubeIDE 建立最小工程，先验证时钟、UART 日志、RTC 唤醒和 Stop 恢复，再接传感器。
5. 单独跑通 SPI、I2C 和 ADC DMA 后，再按 [任务与数据流](docs/02_任务与数据流.md) 接入统一采集窗口、算法和 FreeRTOS 任务。
6. 每完成一个里程碑，按 [验证清单](docs/04_验证清单.md) 保存配置、日志、原始数据和功耗证据。

PC 侧离线分析环境可在 PowerShell 中按需创建：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\tools\requirements.txt
```

以上命令只准备 Python 分析环境，不会生成或验证 MCU 固件。

## 目录说明

- `config/`：采样、特征、告警和低功耗参数样例。
- `docs/`：需求、架构、物料、路线图和验收口径。
- `firmware/`：确认硬件基线后放置 STM32CubeIDE/FreeRTOS 工程。
- `hardware/`：硬件基线、接线、模拟前端和功耗测量记录。
- `tests/`：离线样本、算法对照、故障注入和真机测试记录。
- `tools/`：PC 侧数据分析、配置检查和报告辅助工具。

当前暂定接线见 [STM32F103ZET6 引脚分配](hardware/引脚分配_暂定方案.md)；它已结合精英板 V2 IO 表规避板载 Flash、LCD、按键和串口冲突，待实物板卡修订、跳线和电气状态复核后才是正式接线表。

## 首版可演示闭环

`RTC 唤醒 -> 自检 -> 固定窗口采集 -> 特征提取 -> 连续超限判定 -> 串口上报 -> Stop`

只有在真实硬件上完成对应测试并保留证据后，才能将驱动、低功耗、算法精度或稳定性写成已实现能力。

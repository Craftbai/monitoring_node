# M1-B 测试计划

本文档记录 M1-B 阶段的板级冒烟测试计划和用户代码实现指南。

---

## 1. 测试目标

验证 STM32F103ZET6 开发板基础功能：
- ST-Link 连接和芯片识别
- UART 日志输出
- GPIO 驱动能力
- RTC LSE 起振
- Stop 模式和 RTC Alarm 唤醒

## 3. 用户代码实现

### 3.1 UART 日志输出（printf 重定向）

**位置**：`Core/Src/main.c`

**步骤 1**：在 `main.c` 文件顶部添加重定向函数

```c
/* USER CODE BEGIN Includes */
#include <stdio.h>
/* USER CODE END Includes */

/* USER CODE BEGIN 0 */
// printf 重定向到 USART1
int _write(int file, char *ptr, int len)
{
  HAL_UART_Transmit(&huart1, (uint8_t *)ptr, len, HAL_MAX_DELAY);
  return len;
}
/* USER CODE END 0 */
```

**步骤 2**：在 `main()` 函数的 `USER CODE BEGIN 2` 区域添加系统信息输出

```c
/* USER CODE BEGIN 2 */
printf("\r\n=== System Init ===\r\n");
printf("SYSCLK: %lu Hz\r\n", HAL_RCC_GetSysClockFreq());
printf("HCLK: %lu Hz\r\n", HAL_RCC_GetHCLKFreq());
printf("APB1: %lu Hz\r\n", HAL_RCC_GetPCLK1Freq());
printf("APB2: %lu Hz\r\n", HAL_RCC_GetPCLK2Freq());
printf("RTC Clock: LSE 32768 Hz\r\n");
printf("===================\r\n\r\n");
/* USER CODE END 2 */
```

**预期输出**（串口工具，115200 8N1）：
```
=== System Init ===
SYSCLK: 72000000 Hz
HCLK: 72000000 Hz
APB1: 36000000 Hz
APB2: 72000000 Hz
RTC Clock: LSE 32768 Hz
===================
```

### 3.2 LED 翻转测试

**步骤**：在 `main()` 函数的 `while(1)` 循环中添加 LED 翻转代码

```c
/* USER CODE BEGIN WHILE */
static uint32_t tick_last = 0;
while (1)
{
  uint32_t tick_now = HAL_GetTick();
  
  // 每 500 ms 翻转 LED0
  if (tick_now - tick_last >= 500)
  {
    tick_last = tick_now;
    HAL_GPIO_TogglePin(LED0_GPIO_Port, LED0_Pin);
    printf("[%lu] LED Toggle\r\n", tick_now);
  }
  
  /* USER CODE END WHILE */
  
  /* USER CODE BEGIN 3 */
}
/* USER CODE END 3 */
```

**预期现象**：
- LED0（PB5）每 500 ms 翻转一次（亮/灭）
- UART 输出：
  ```
  [500] LED Toggle
  [1000] LED Toggle
  [1500] LED Toggle
  ```

**LED 极性验证**：
- 若 `HAL_GPIO_TogglePin` 后 LED 翻转正常 → LED 极性正确
- 若 LED 始终不亮或不灭 → 检查 PB5 硬件连接

---

### 3.3 GPIO 波形测试

**步骤**：在 LED 翻转代码中同时翻转 TRACE_PIN

```c
if (tick_now - tick_last >= 500)
{
  tick_last = tick_now;
  HAL_GPIO_TogglePin(LED0_GPIO_Port, LED0_Pin);
  HAL_GPIO_TogglePin(TRACE_PIN_GPIO_Port, TRACE_PIN_Pin);  // 添加此行
  printf("[%lu] LED Toggle\r\n", tick_now);
}
```

**示波器测量**：
1. 探头连接 PD11（TRACE_PIN）
2. 触发模式：边沿触发（上升沿或下降沿）
3. 时基：100 ms/div

**预期波形**：
- 方波频率：1 Hz（周期 1000 ms）
- 高电平：3.3V
- 低电平：0V
- 占空比：50%

### 3.4 RTC LSE 起振验证

**方法 1**：调试器读取寄存器

1. 在 CubeIDE 中进入调试模式（F11）
2. 打开 `Memory Browser`（Window → Show View → Memory Browser）
3. 输入地址 `0x40021020`（RCC_BDCR 寄存器）
4. 检查读取值

**预期值**：
- `RCC_BDCR = 0x0000_8103`
  - bit 1 (LSERDY) = 1 → LSE 起振成功
  - bit 0 (LSEON) = 1 → LSE 使能
  - bit 8-9 (RTCSEL) = 01 → RTC 时钟源为 LSE

**方法 2**：代码打印 RTC 计数器

在 `USER CODE BEGIN 2` 区域添加：

```c
/* USER CODE BEGIN 2 */
// ... 前面的系统信息输出 ...

// 读取 RTC 计数器
uint32_t rtc_cnt = HAL_RTCEx_BKUPRead(&hrtc, RTC_BKP_DR1);
printf("RTC Counter: %lu\r\n", rtc_cnt);

// 等待 2 秒后再读一次
HAL_Delay(2000);
rtc_cnt = HAL_RTCEx_BKUPRead(&hrtc, RTC_BKP_DR1);
printf("RTC Counter (after 2s): %lu\r\n", rtc_cnt);
printf("RTC LSE Running: %s\r\n\r\n", (rtc_cnt > 0) ? "YES" : "NEED CHECK");
/* USER CODE END 2 */
```

**预期输出**：
```
RTC Counter: 12345
RTC Counter (after 2s): 78123
RTC LSE Running: YES
```

**如果 RTC 不起振**：
- 检查 PC14/PC15 焊接是否良好
- 检查 32.768 kHz 晶振是否损坏
- 备选方案：使用内部 LSI（40 kHz，精度较低）

### 3.5 Stop 模式和 RTC Alarm 唤醒测试

**步骤 1**：在 `main()` 函数的 `USER CODE BEGIN 2` 区域添加 Stop 测试代码

```c
/* USER CODE BEGIN 2 */
// ... 前面的系统信息和 RTC 验证代码 ...

printf("=== Stop Mode Test ===\r\n");
printf("Entering Stop Mode in 3 seconds...\r\n");
HAL_Delay(3000);

// 配置 RTC Alarm A，5 秒后唤醒
RTC_AlarmTypeDef sAlarm = {0};
RTC_TimeTypeDef sTime = {0};

// 获取当前时间
HAL_RTC_GetTime(&hrtc, &sTime, RTC_FORMAT_BIN);

// 设置 Alarm 时间（当前时间 + 5 秒）
sAlarm.Alarm = RTC_ALARM_A;
sAlarm.AlarmTime.Hours = sTime.Hours;
sAlarm.AlarmTime.Minutes = sTime.Minutes;
sAlarm.AlarmTime.Seconds = (sTime.Seconds + 5) % 60;

// 启用 Alarm 中断
if (HAL_RTC_SetAlarm_IT(&hrtc, &sAlarm, RTC_FORMAT_BIN) != HAL_OK)
{
  printf("ERROR: RTC Alarm set failed\r\n");
  Error_Handler();
}

printf("RTC Alarm set: wake up in 5 seconds\r\n");
printf("Entering Stop Mode NOW...\r\n");
HAL_Delay(100);  // 确保 UART 发送完成

// 进入 Stop 模式
HAL_PWR_EnterSTOPMode(PWR_LOWPOWERREGULATOR_ON, PWR_STOPENTRY_WFI);

// === 唤醒后执行以下代码 ===

// 重新配置系统时钟（Stop 后 HSE 和 PLL 关闭）
SystemClock_Config();

printf("\r\n=== Wake Up from Stop ===\r\n");
printf("RTC Alarm triggered!\r\n");
printf("System Clock restored to 72 MHz\r\n");
printf("Resuming normal operation...\r\n\r\n");
/* USER CODE END 2 */
```

**步骤 2**：添加 RTC Alarm 中断回调函数

在 `main.c` 的 `USER CODE BEGIN 4` 区域添加：

```c
/* USER CODE BEGIN 4 */
// RTC Alarm 中断回调
void HAL_RTC_AlarmAEventCallback(RTC_HandleTypeDef *hrtc)
{
  // 中断中不要使用 printf（UART 可能未初始化）
  // 只需要触发唤醒即可
}
/* USER CODE END 4 */
```

**预期输出**：
```
=== Stop Mode Test ===
Entering Stop Mode in 3 seconds...
RTC Alarm set: wake up in 5 seconds
Entering Stop Mode NOW...

=== Wake Up from Stop ===
RTC Alarm triggered!
System Clock restored to 72 MHz
Resuming normal operation...
```

**预期功耗**：
- Stop 模式电流：< 100 μA（万用表测量 3.3V 供电线）
- 唤醒时间：< 10 ms（示波器测量 TRACE_PIN 波形）

## 5. 故障排查

### 5.1 UART 无输出

**可能原因**：
- P3 跳线帽未短接（CH340 未连接到 PA9/PA10）
- 串口工具配置错误（波特率、数据位、停止位）
- USART1 初始化失败

**排查步骤**：
1. 检查 P3 跳线帽是否短接
2. 验证串口工具配置：115200 8N1
3. 在调试器中单步执行 `HAL_UART_Transmit`，检查返回值

---

### 5.2 LSE 不起振

**可能原因**：
- 32.768 kHz 晶振损坏或焊接不良
- PC14/PC15 引脚虚焊
- 负载电容不匹配

**排查步骤**：
1. 示波器测量 PC14/PC15 波形（应为正弦波，幅度 0.5-1.5V）
2. 检查晶振焊接
3. 备选方案：使用内部 LSI（40 kHz），在 CubeMX 中 RCC → LSE 改为 `Disable`，RTCSEL 改为 LSI

---

### 5.3 Stop 模式无法唤醒

**可能原因**：
- RTC Alarm 中断未使能
- EXTI Line 17 未配置
- NVIC 中断优先级错误

**排查步骤**：
1. 在调试器中检查 `RTC_CRH` 寄存器（地址 0x40002804），ALRIE 位应为 1
2. 检查 `EXTI_IMR` 寄存器（地址 0x40010400），bit 17 应为 1
3. 验证 NVIC 中 `RTC_Alarm_IRQn` 已使能

---

### 5.4 唤醒后系统异常

**可能原因**：
- 唤醒后未重新配置系统时钟（HSE 和 PLL 关闭）
- UART 外设未重新初始化

**排查步骤**：
1. 确认唤醒后调用了 `SystemClock_Config()`
2. 检查 `RCC_CR` 寄存器（地址 0x40021000），HSERDY 和 PLLRDY 应为 1

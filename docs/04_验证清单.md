# 验证清单

本清单区分文档/静态检查、PC 参考、目标板、真实传感器和整机长稳五个层级。低层级通过不能替代高层级结论；未执行的项目保持未勾选。

## 1. M0 基线与文档

- [ ] 根 README 的五个文档链接可达，且没有把计划写成已实现。
- [ ] 已由[硬件基线模板](../hardware/硬件基线模板.md)生成 `hardware/硬件基线.md`，关键项没有“待确认”。
- [ ] MCU、传感器、电流前端、供电、引脚、工具链和仪器版本均有来源记录。
- [ ] [`config/thresholds.example.json`](../config/thresholds.example.json) 可被 JSON 解析，采样率、FFT 点数、频带和阈值单位有解释。
- [ ] 本地配置、原始采样和日志路径未包含真实密钥或现场敏感信息。

## 2. M1 板级冒烟

- [ ] 固件可下载并输出启动版本、复位原因和配置版本。
- [ ] UART、测试 GPIO、RTC 唤醒和 Stop 进出均有波形或日志证据。
- [ ] 唤醒后系统时钟、HAL 时基和调试输出恢复正常。
- [ ] 记录构建工具、固件哈希、板卡、供电和测试日期。

## 3. M2 驱动与采集

- [ ] SPI 振动器件 ID、配置回读和原始数据读数稳定。
- [ ] I2C 温度读数与可信仪表在至少两个点合理一致。
- [ ] ADC DMA 半缓冲和全缓冲均可处理，不覆盖未消费数据。
- [ ] SPI/I2C 超时、错误 ID、总线恢复和器件复位路径可复现。
- [ ] FIFO 溢出、DMA 溢出、块池耗尽和序号断裂均有计数与无效标志。
- [ ] 所有原始数据包含 `cycle_id`、序号、采样率、时间戳和标定信息。

## 4. M3 PC 算法参考

- [ ] 已保存正常、轻微异常、持续异常、零输入、单频、冲击、截幅和缺样样本。
- [ ] Python 浮点参考覆盖去直流、窗函数、RMS、峰峰值、峰值因子和频带能量。
- [ ] FFT 归一化、窗增益、单边谱倍增和频带端点规则已固定。
- [ ] 合法输入、边界输入和无效输入均有自动化断言。

## 5. M4 CMSIS-DSP 与一致性

- [ ] MCU 与 PC 使用相同原始样本、采样率和窗口配置。
- [ ] 浮点实现结果与 PC 参考在定义的误差范围内一致。
- [ ] Q15 实现若启用，已记录缩放、饱和次数和误差；没有把溢出隐藏为正常值。
- [ ] 处理耗时、任务栈高水位、块池峰值占用和队列深度有记录。

## 6. M5 FreeRTOS 闭环

- [ ] 周期状态可完整经过 `SELF_TEST -> ACQUIRE -> PROCESS -> EVALUATE -> REPORT -> PREPARE_STOP`。
- [ ] 正常、轻微异常和持续异常三类输入能稳定验证连续确认与迟滞逻辑。
- [ ] 传感器断开时该通道标记无效，不输出虚假正常数值。
- [ ] 上报超时有界，不阻塞后续周期，也不无限重试。
- [ ] 任务心跳、栈水位、队列水位和错误计数进入诊断输出。
- [ ] 任意关键任务卡死或总线连续错误时，健康监测不会无条件喂狗。

## 7. M6 低功耗与 M7 整机

- [ ] 已分别测量运行、采集、处理、上报、唤醒过渡和 Stop 电流。
- [ ] RTC 连续唤醒至少 100 个周期，`cycle_id` 连续且无死锁或块泄漏。
- [ ] Stop 前所有 DMA、队列、传感器电源和唤醒源满足架构门禁。
- [ ] 上报失败、传感器断开、看门狗复位和异常唤醒均能形成可关联证据。
- [ ] 低压风扇正常、扰动、温升和断线场景均有原始数据、结果和视频/日志。
- [ ] 功耗、算法、稳定性和硬件能力的结论均标明验证层级。

## 8. 重点异常矩阵

| 输入或故障 | 预期结果 | 证据 |
| --- | --- | --- |
| SPI/I2C 无应答 | 有界超时、恢复或通道无效 | 总线波形、错误计数、周期结果 |
| DMA/FIFO 溢出 | 丢块计数增加，相关特征无效 | 序号、标志位和日志 |
| ADC 输入饱和 | 标记饱和，不使用该值触发正常告警 | 原始数据和结果 |
| 重复超限 | 达到 N 个有效周期后才进入 `ACTIVE` | 周期结果序列 |
| 短暂无效周期 | 不清除已有告警，不计作正常 | 状态机日志 |
| 上报超时 | 达到截止时间后收尾并进入 Stop | 超时与收尾记录 |
| 任务卡死 | 健康监测拒绝喂狗，保留复位原因 | 看门狗/复位日志 |
| Stop 唤醒 | 恢复时钟、外设和下一个 `cycle_id` | GPIO 波形、串口日志 |

## 9. 证据层级

| 层级 | 能证明 | 不能证明 |
| --- | --- | --- |
| 文档/静态检查 | 设计口径和链接一致 | 驱动和硬件行为 |
| PC 算法 | 公式、边界和参考结果 | MCU 定点误差和实时性 |
| 目标板 | 工程下载、任务、外设和低功耗行为 | 真实传感器测量准确度 |
| 真实传感器 | 接线、标定、采样和告警场景 | 生产环境长期可靠性 |
| 整机长稳 | 指定条件下的周期稳定和实测功耗 | 未覆盖场景、量产质量和安全认证 |

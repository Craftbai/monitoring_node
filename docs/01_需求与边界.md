# 需求与边界

## 功能范围

- 采集振动、温度和低压电流信号。
- 通过 FreeRTOS 组织采集、处理、上报和健康监测任务。
- 使用 DMA、队列和信号量降低采集与处理之间的耦合。
- 使用 CMSIS-DSP 做定点 FFT 和基础时域/频域特征提取。
- 使用连续确认机制减少偶发噪声导致的误告警。

## 低功耗边界

持续高频振动采样和长期 Stop 模式不能同时成立。首版采用“RTC 唤醒 -> 采集固定窗口 -> 处理/上报 -> Stop”的周期性策略；若后续需要连续状态监测，应明确增加运行功耗和供电方案。

## 安全边界

- 首版仅采集低压直流风扇或隔离传感器输出，不直接采样市电或工业电机电流。
- 告警先通过串口、LED 或上位机显示，不接入生产停机联锁。
